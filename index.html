Keep it on your Home Screen

Solo is made to run as an app. From the Home Screen it opens edge to edge, without Safari’s bars, and remembers your photo.

  1. Tap Share in Safari.
  2. Choose Add to Home Screen.
  3. Tap Add, then open Solo from the icon.

Close the lid to fold

The smooth fold needs a small helper on your Mac. It polls the hinge on your machine and nothing is uploaded. The first run sets up its own Python environment, so you do not install anything system-wide.

  1. Download lid-bridge.py.
  2. In Terminal, run the command below.
  3. Close the lid slowly.
python3 ~/Downloads/lid-bridge.py

Chrome can Allow the lid sensor instead, without Terminal, but that path only updates about once a second.
